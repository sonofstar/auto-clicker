# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2025-07-30

### Added
- Auto-clicker with configurable interval (1~60000 ms)
- Support for left, right, and middle mouse button clicking
- Fixed count or infinite clicking mode
- Follow cursor position or custom X/Y coordinate clicking
- Mouse click and keyboard press recording
- Playback with adjustable speed (0.5x, 1x, 2x, 4x, 8x)
- Recording save/load as JSON files
- Real-time action list display
- Global hotkeys: F6 (clicker), F7 (record), F8 (playback), ESC (emergency stop)
- Dark theme GUI with tabbed interface
- Single-file Windows exe packaging via PyInstaller

### Changed
- 添加了自动连点功能 / Added auto-clicker feature
- 添加了操作录制与回放功能 / Added macro recording and playback
- 添加了中英文双语文档 / Added bilingual documentation (Chinese & English)
